# ASHFALL — Tactical Map V3, integration expérimentale

**À installer sur GitHub `main` : NON.**

Cette archive est une COPIE COMPLETE de laboratoire, pas un patch approuvé.

- L'ancienne cartographie V31 est conservée par branchement explicite.
- Pour V32, rectangles basés sur les dimensions `x,y,w,h` du monde physique.
- Portes basées sur les portails partagés, visibles si les deux salles sont connues.
- Brouillard et POI fondés sur les salles découvertes.
- Marqueur actualisé en continu en coordonnées mondiales; mini-carte centrée sur le joueur.
- La carte principale conserve le défilement déjà présent dans le vrai jeu.
- Aucun changement aux combats, objets, interactions, commandes ou sauvegardes.

## Limitations

- La carte principale V32 dispose du pincement tactile, de commandes +/−, du recentrage et du cadrage global. Le résultat visuel sur Safari iPhone reste à tester.
- Aucune validation Safari/iPhone ni test de gameplay complet n'est revendiquée.
- Les chemins et passages secrets devront faire l'objet de validations en jeu.
- Le ZIP est pour un environnement de test séparé, jamais pour `main`.
