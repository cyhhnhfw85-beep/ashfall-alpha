# Installer et tester ASHFALL 0.9.2-graphics-p2.1 sur iPhone

1. Décompresser le ZIP complet de la version `ASHFALL 0.9.2 Graphics P2.1`.
2. Remplacer tous les fichiers de la version de test locale par ceux du ZIP P2.1.
3. Ouvrir le jeu dans Safari / la PWA et vérifier l'identifiant visible **`0.9.2-graphics-p2.1`**.
4. Si un ancien cache persiste, recharger la page, fermer/réouvrir l'app puis vérifier que la version installée affiche bien `0.9.2-graphics-p2.1`.
5. Recette minimale recommandée :
   - ouverture du jeu ;
   - refuge ;
   - départ en expédition ;
   - déplacement du Nomade ;
   - lisibilité arme / posture ;
   - lecture du sac ;
   - coffre + extraction ;
   - fermeture / reprise ;
   - démarrage hors ligne.
