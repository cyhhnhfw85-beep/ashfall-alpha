# ASHFALL V9.2.8 — Équipements 3.0 (première passe)

- Les fiches et comparaisons affichent les effets calculés depuis la fonction `buff()` du moteur, sans modifier les valeurs ou les sauvegardes.
- Suppression dans les descriptions de l’affichage générique « Efficacité / Résistance / Réactivité ». L’endurance statique apparaît comme PV supplémentaires ; les bottes présentent leur vitesse complémentaire.
- Quinze modèles standards disposent chacun d’une illustration SVG vectorielle propre, au lieu d’un pictogramme unique par catégorie. Les modèles hérités disposent d’une illustration de famille.
- Cadrage `object-fit:contain` sur les images d’armes dans le sac et les comparatifs.
- Comparaison entre objets d’un même effet uniquement. Effets différents signalés sans comparer abusivement deux valeurs incompatibles.
- Pas de modification de génération, loot, combat, économie ni sauvegarde.

Limites : les visuels SVG sont des illustrations vectorielles détaillées de première passe, non des peintures d’objet individuelles photoréalistes. Les joueurs doivent valider le rendu iPhone, notamment la taille des comparatifs.
