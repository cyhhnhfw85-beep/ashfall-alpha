ASHFALL — Monde 1 fixe, ALPHA DE TEST ISOLÉE
============================================
Base conservée : ASHFALL 0.9.3 PERIPHERIE P03 B3 FULL TEST1.
Cette archive contient TOUS les fichiers du jeu d'origine plus une expérience alpha indépendante.
IMPORTANT : ce n'est PAS la grosse mise à jour finale. La structure de 12 salles fonctionne dans un mode séparé de la progression d'origine, et 11 décors sont encore des maquettes fixes provisoires.

INSTALLATION SUR PC :
1. Décompresser TOUTE l'archive dans un dossier (ne pas ouvrir index.html à l'intérieur du ZIP).
2. Démarrer un serveur local, par exemple dans ce dossier : python -m http.server 8000
3. Ouvrir http://localhost:8000/index.html dans Chrome.
4. Dans le refuge, ouvrir SECTEURS / PROGRESSION.
5. Cliquer « TEST MONDE 1 FIXE · 12 SALLES (ALPHA) ».
6. PC : WASD ou flèches ; sur mobile : glisser sur la zone de jeu pour se déplacer. Tir automatique et coffre automatique.
7. Bouton Retour au refuge pour quitter le mode test.

Contenu de cette alpha :
- 12 pièces aux dimensions et connexions fixes ; progression 01 -> 02 -> 05 -> 06 -> 09 -> 10 -> 11 -> 12 et branches 03, 04, 07, 08.
- Salle 01 : illustration source déjà approuvée (sa porte nord peinte reste visible dans cette alpha).
- Salles 02–12 : décors provisoires fixes générés à l'avance, PAS les illustrations finales.
- Combats et vagues simplifiés, tir automatique, portes verrouillées pendant le combat.
- Console simplifiée, coffres aléatoires, extraction intermédiaire et finale, boss à deux phases.
- Les crédits, composants, équipements et l'accès au Monde 2 de CE MODE ALPHA NE SONT PAS transférés à la sauvegarde principale : progression distincte sous ashfall_fixed_m1_alpha.
- L'inventaire, équipements, économie et comportement fin de partie du jeu original demeurent dans le mode principal inchangé.

LIMITES :
- IA, attaques et boss : PROTOTYPES de gameplay. Pas encore tous les patterns télégraphiés finaux.
- La cinématique et l'écran de victoire finaux ne sont pas intégrés ; résumé provisoire.
- Collisions du fond 01 à caler précisément et porte nord à nettoyer artistiquement.
- Tests automatisés : scripts JS contrôlés et plan 11/11 connexions vérifié, mais pas de validation réelle navigateur : environnement bloque la navigation locale.
- Sauvegardes : backup de vos sauvegardes habituelles recommandé avant toute expérimentation et particulièrement avant publication.
- Aucun déploiement GitHub effectué.

ATTENTION : NE PAS PUBLIER EN REMPLACEMENT DE MAIN SANS TESTS sur PC et iPhone.
